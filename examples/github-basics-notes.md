## 1. Repositories and history

Git tracks versions; GitHub hosts repositories and supports collaboration. A repository holds project files and revision history. A README introduces the project. A commit records a set of changes with a message and identifier. Saving or committing locally does not, by itself, upload changes to GitHub.

Sources: [GitHub Docs: What is GitHub?](https://docs.github.com/en/get-started/start-your-journey/what-is-github), [GitHub Docs: About repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories), [GitHub Docs: Commits](https://docs.github.com/en/pull-requests/reference/commits), [GitHub Docs: Hello World](https://docs.github.com/en/get-started/using-github/hello-world)

## 2. From branch to pull request

A branch lets you work separately from the default branch. For this exercise, start a branch, edit a file, commit and push the change, then open a pull request. A pull request proposes merging changes into a base branch and gives collaborators a place to discuss them. Opening it does not itself merge the change. Inspect the proposed changes before merging.

Sources: [GitHub Docs: GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow), [GitHub Docs: Hello World](https://docs.github.com/en/get-started/using-github/hello-world)

## 3. Forks, clones, and issues

A fork is a separate repository on GitHub connected to an upstream project. It can let you propose a contribution without changing the original directly. A clone downloads repository data to your computer. Issues track work such as bugs and ideas; pull requests propose code or file changes. Reporting a bug does not automatically fix or merge anything.

Sources: [GitHub Docs: About repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories), [GitHub Docs: Fork a repository](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo), [GitHub Docs: About issues](https://docs.github.com/en/issues/tracking-your-work-with-issues/learning-about-issues/about-issues)

## Practice outside the app

In a disposable repository, make a README change on a branch, commit it with a useful message, open a pull request, inspect the diff, and merge when appropriate. This optional practice is not automatically checked or awarded XP.
